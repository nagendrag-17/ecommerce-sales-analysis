# Olist E-Commerce Sales Analysis

## Project Overview
This project analyzes e-commerce sales and customer behaviour using the Olist dataset. The objective is to identify sales trends, understand customer activity and evaluate business performance.

## Tools Used
- SQL – Data analysis and querying
- Python (Pandas) – Data cleaning and preparation
- Microsoft Excel – Data analysis and interactive dashboard

## Project Workflow
1. Collected and explored the dataset.
2. Cleaned and prepared the data using Python.
3. Performed business analysis using SQL.
4. Analyzed sales and business metrics in Excel.
5. Created an interactive Excel dashboard.
